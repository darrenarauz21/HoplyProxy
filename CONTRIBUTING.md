# Contribuir a Hoply Proxy

[English](#contributing-to-hoply-proxy) · **Español**

¡Gracias por querer apoyar el proyecto! Las ideas, los reportes de errores, las traducciones y el
código son bienvenidos.

## Cómo aportar

1. Abra un *issue* para contar el error o la idea antes de trabajar en algo grande.
2. Haga un fork, cree una rama y envíe un *pull request* con una descripción breve.
3. Si cambia la app de escritorio, ejecute `dotnet test Desktop/Hoply.Desktop.slnx` antes de enviarlo.

# Contributing to Hoply Proxy

**English** · [Español](#contribuir-a-hoply-proxy)

Thanks for wanting to support the project! Ideas, bug reports, translations and code are welcome.

## How to contribute

1. Open an issue describing the bug or idea before working on something big.
2. Fork the repo, create a branch and send a pull request with a short description.
3. If you change the desktop app, run `dotnet test Desktop/Hoply.Desktop.slnx` before sending it.
